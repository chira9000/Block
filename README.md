# Block
# The goal of our project is to use heat maps/weather database to create optiaml routes for truck drivers that guarantee the transport of food supplies, ending world hunger. 
# 

0–1	Create the Android project, Firebase project, Maps and Routes API keys, debug SHA-1 in Firebase, and google-services.json. Get a blank map on a real device. Deploy a Spring Boot “hello” to Cloud Run now.
1–2	Auth screens, Navigation graph, role-based routing
2–4	Backend: hazard fetchers and the /hazards endpoint (do the 2 easiest sources first: USGS and NWS). App: map and heatmap overlay with toggles.
4–5	Routes API via Retrofit, polylines drawn on the map
5–7	Scoring: polyline sampler, exposure function, synthetic dataset, Smile training class, /score endpoint, token verification. Java fallback scorer on the phone.
7–8	Integration: ranked route cards, save trips, admin dashboard and approval flow
8–9	Lock Firestore rules, build a signed release APK, test on 2 devices and 1 emulator
9–10	Demo script, slides, rehearse twice, record a backup screen recording
